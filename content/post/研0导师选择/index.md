# 导师选择

卓越工程师计划要求必须花一年时间在企业实习，研一在学校，研二在企业，导师的研究方向和企业的方向不同该如何考虑和抉择？研究生三年该如何度过

第一，我们学院几乎没有和企业方向一致的导师，即使要换其他导师，也找不到什么好方向的

第二，那方向不怎么好的话，可不可以选一个不怎么push的导师，这样自己有时间做自己的事情

第三，现在选的导师的方向虽然自己不是特别了解，也不是当前最好的方向，但导师的履历是国内顶尖水平，我跟着他干，可以从导师身上学一些做事方法论层面的东西；其次，我可以获得导师的资源，包括但不限于人脉，物质方面的资源；第三，我是导师的开山大弟子，我可以获得导师的一对一指导，可以和导师有很好的关系，可以获得导师的关注
