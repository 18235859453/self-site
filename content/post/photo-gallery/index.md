Stack 主题内置相册功能，只需将多张图片并排放在同一行，就会自动拼成画廊，点击可放大浏览。

## 如何使用

将图片放在文章同级目录，在 Markdown 中这样写：

```markdown
![图片1](image1.jpg)  ![图片2](image2.jpg)

![图片3](image3.jpg)  ![图片4](image4.jpg)
```

> 注意：同一行的图片之间用**两个空格**隔开，不同行之间正常换行。
